# Kategori Resimleri

Bu klasöre aşağıdaki resimleri yükleyin:

## Gerekli Resimler:

1. **donerler-bg.jpg** - Dönerler kategorisi için arka plan resmi

   - Önerilen boyut: 400x600px veya 600x800px
   - Döner, dürüm, et gibi görseller içermeli

2. **servisler-bg.jpg** - Servisler kategorisi için arka plan resmi

   - Önerilen boyut: 400x600px veya 600x800px
   - Büyük porsiyonlar, aile boyu menüler

3. **burgerler-bg.jpg** - Burgerler kategorisi için arka plan resmi

   - Önerilen boyut: 400x600px veya 600x800px
   - Burger, hamburger görselleri

4. **icecekler-bg.jpg** - İçecekler kategorisi için arka plan resmi

   - Önerilen boyut: 400x600px veya 600x800px
   - İçecek, kola, ayran, su gibi görseller

5. **atistirmaliklar-bg.jpg** - Atıştırmalıklar kategorisi için arka plan resmi
   - Önerilen boyut: 400x600px veya 600x800px
   - Patates kızartması, soğan halkası gibi görseller

## Önemli Notlar:

- Resimler yüksek kalitede olmalı
- Dikey (portrait) format tercih edilir
- Resimlerde metin olmamalı (sadece görsel)
- JPG formatı kullanın
- Dosya isimleri tam olarak yukarıdaki gibi olmalı
